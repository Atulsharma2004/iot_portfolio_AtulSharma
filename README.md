# iot_portfolio_AtulSharma

Embedded Systems & IoT Firmware Engineer portfolio for **Atul Sharma** — separate from the general web portfolio on [GitHub](https://github.com/Atulsharma2004).

## Features

- Dark/light mode with glassmorphism UI
- Interactive PCB circuit trace background
- Animated device architecture (Sensors → MCU → RTOS → Connectivity → Cloud)
- Production projects: Qualcomm Open CPU, QCC748, ESP32-P4, STM32, payment terminals
- GitHub repository cards for embedded open-source work
- RTOS scheduler, UART protocol, cellular IoT, and telemetry demos
- Fully responsive, mobile-first design
- SEO-optimized for embedded engineering keywords

## Quick Start

```bash
git clone https://github.com/Atulsharma2004/iot_portfolio_AtulSharma.git
cd iot_portfolio_AtulSharma
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for Production

```bash
npm run build
npm run preview
```

### Deploy to Vercel

1. Push this repo to `github.com/Atulsharma2004/iot_portfolio_AtulSharma`
2. Import the repository at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Vite — use **Build Command** `npm run build` and **Output Directory** `dist`

Or deploy from CLI: `npx vercel --prod`
