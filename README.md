# Atul Sharma — Embedded Systems & IoT Portfolio

A world-class, recruiter-focused portfolio website for **Atul Sharma**, Embedded Systems & IoT Firmware Engineer.

## Features

- Dark/light mode with glassmorphism UI
- Interactive PCB circuit trace background
- Animated device architecture (Sensors → MCU → RTOS → Connectivity → Cloud)
- Production projects: Qualcomm Open CPU, QCC748, ESP32-P4, STM32, payment terminals
- GitHub repository cards for embedded open-source work
- RTOS scheduler, UART protocol, cellular IoT, and telemetry demos
- Fully responsive, mobile-first design
- SEO-optimized for embedded engineering keywords

## Quick Start

```bash
cd atul-sharma-portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for Production

```bash
npm run build
npm run preview
```

Deploy the `dist/` folder to GitHub Pages, Netlify, or Vercel.

## Resume

Place your resume PDF at:

## Customize

- **Content**: Edit `src/data/portfolio.js`
- **GitHub repos**: Edit `src/data/github-repos.json`
- **Styles**: Edit `src/styles/main.css`

## Tech Stack

- Vite 6
- Vanilla HTML/CSS/JS (no framework overhead)
- Canvas API for PCB animations
